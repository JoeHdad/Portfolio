# Yousef Haddad – Portfolio

Personal portfolio of **Yousef Haddad**, Full-Stack Software Engineer & AI Automation Engineer.

Live: **https://yousefhaddad.netlify.app**

## Tech stack

- React 18 + TypeScript, built with Vite
- Tailwind CSS and shadcn/ui components
- Framer Motion for animations
- Netlify (hosting)
- Web3Forms for the contact form

## Run locally

```bash
git clone https://github.com/JoeHdad/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Then open http://localhost:8080.

## Where to edit content

| Section | File |
|---|---|
| Hero (headline, links, CV button) | `src/components/Hero.tsx` |
| About, experience timeline, education, certifications | `src/components/About.tsx` |
| Skills | `src/components/Technologies.tsx` |
| Core capabilities | `src/components/ui/features-section-demo-2.tsx` |
| Projects | `src/components/Projects.tsx` |
| Contact info and form | `src/components/Contact.tsx` |
| CV download | `public/Yousef_Haddad_CV.pdf` |
| SEO / social preview | `index.html`, `public/og-image.png` |

## Build & deploy

```bash
npm run build   # outputs to dist/
```

Netlify builds automatically from the `main` branch using `netlify.toml`.
